# Predicting-Next-Day-Rainfall-Using-10-Years-of-Weather-Data
A Machine Learning project that predicts whether it will rain the next day using 10 years of historical weather data and Logistic Regression classification.

This project uses Logistic Regression to predict next-day rainfall based on historical weather observations collected over a 10-year period. The model analyzes meteorological features such as temperature, humidity, pressure, wind speed, and rainfall patterns to classify whether rain is likely to occur the following day. The project includes data preprocessing, feature engineering, model training, and performance evaluation.

## Key Features

Analysis of 10 years of weather data
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Feature selection and engineering
Logistic Regression classification model
Model evaluation using Accuracy, Precision, Recall, and F1-Score
Next-day rainfall prediction based on weather conditions
Data visualization and performance insights
